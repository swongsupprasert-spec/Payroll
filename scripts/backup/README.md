# สำรองข้อมูล eSimPayroll (เข้ารหัส → Google Drive)

สำรองทุกตารางใน Supabase (`public`) ทุกวัน 12:30 น. เข้ารหัสในเครื่องก่อนเก็บลงโฟลเดอร์ Google Drive
ไฟล์ `.esb` เปิดได้เฉพาะคนที่มี **ไฟล์กุญแจกู้คืน + รหัสผ่านกุญแจ** — Google หรือคนที่เข้าโฟลเดอร์ได้อ่านข้างในไม่ได้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `setup.mjs` | ตั้งค่าครั้งแรก: ลิงก์ฐานข้อมูล (บัญชีอ่านอย่างเดียว), โฟลเดอร์ Google Drive, สร้างกุญแจ, สำรองครั้งแรก, ตั้งเวลา |
| `backup.mjs` | สำรอง 1 ครั้ง (Task Scheduler เรียกทุกวัน) · เก็บ 30 วันล่าสุด + ไฟล์แรกของแต่ละเดือน 12 เดือน |
| `restore.mjs` | เปิดไฟล์ `.esb` เป็น JSON (ต้องใช้กุญแจกู้คืน + รหัสผ่าน) |

## ตั้งค่าครั้งแรก
1. ติดตั้ง **Google Drive for desktop** แล้วล็อกอินบัญชีที่เป็นเจ้าของโฟลเดอร์สำรอง
   (ถ้าโฟลเดอร์เป็นของคนอื่นที่แชร์มา ให้กด "เพิ่มทางลัดไปยังไดรฟ์" ก่อน จะได้เห็นใน My Drive)
2. Supabase → SQL Editor: เปิด `sql/33-supabase-backup-reader.sql` **แก้รหัสผ่านในไฟล์เป็นของคุณเอง** แล้ว Run
3. เทอร์มินัลในโฟลเดอร์ Payroll: `node scripts/backup/setup.mjs` แล้วทำตามที่ถาม
4. คัดลอกไฟล์ `eSimPayroll-กุญแจกู้คืน-เก็บแยก.pem` บน Desktop ไปเก็บใน USB (อย่างน้อย 2 ที่) **แล้วลบออกจาก Desktop**
   — ห้ามเก็บไฟล์กุญแจไว้ใน Google Drive โฟลเดอร์เดียวกับไฟล์สำรอง

ค่าตั้งเก็บที่ `%USERPROFILE%\.esim-backup\` (เฉพาะผู้ใช้ Windows นี้อ่านได้) · ประวัติการสำรองดูที่ `backup.log` ในโฟลเดอร์นั้น

## กู้คืน
`node scripts/backup/restore.mjs "ที่อยู่ไฟล์.esb"` → ได้ไฟล์ `.json` ข้อมูลทุกตาราง (ไม่ได้เข้ารหัส — ใช้เสร็จลบทิ้ง)
การนำข้อมูลกลับเข้า Supabase ทำทีละตาราง/ทีละบัญชีตามเหตุการณ์ — ให้ทีมพัฒนาช่วย
