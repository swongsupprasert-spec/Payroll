# ไฟล์ SQL ของ Supabase (โปรเจกต์ sfzzswzyoqshlppsturd)

ไฟล์เรียงตาม **ลำดับที่ต้องรัน** (เลขหน้าชื่อไฟล์) — ใช้ตอนติดตั้งฐานข้อมูลใหม่ตั้งแต่ศูนย์ ให้รันใน Supabase SQL Editor ทีละไฟล์จาก 01 ไปจนจบ

- ชื่อหลังเลขลำดับคือชื่อเดิมของไฟล์ ข้อความเตือนในแอป (เช่น "ต้องรัน supabase-checkin-3.sql") จึงยังค้นเจอได้
- หลายไฟล์เขียนทับฟังก์ชันเดิม (เช่น `activate_verified_order` ใน 07, 08, 11, 14) — **ลำดับมีผล** ตัวที่รันทีหลังคือตัวที่ใช้จริง
- ไฟล์ใหม่: ตั้งชื่อเป็นเลขถัดไป เช่น `29-supabase-xxx.sql` และเพิ่มแถวในตารางนี้
